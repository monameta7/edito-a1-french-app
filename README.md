# 🇫🇷 Édito A1 — اپ آموزش فرانسه

اپ وب برای یادگیری فرانسه بر اساس سیلابس کتاب *Édito A1* (نشر Didier) — درس‌ها، تمرین‌های شش‌گانه (واژگان/گرامر/شنیداری/خواندن/نوشتاری/گفتاری)، فلش‌کارت لایتنر، آزمون‌های واحد و DELF نهایی، و یک معلم هوش‌مصنوعی (Claude) برای تصحیح نوشتار و مکالمه زنده.

بدون بک‌اند و بدون build — فقط HTML/CSS/JavaScript خام. پیشرفت هرکس فقط در `localStorage` مرورگر خودش ذخیره می‌شود.

## اجرای محلی

```bash
node start-server.js
```
بعد آدرس `http://localhost:5173` را در مرورگر باز کن.

**چرا نه با دابل‌کلیک روی `index.html`؟** مرورگرها روی صفحاتی که با آدرس `file://` باز شده‌اند، دسترسی به میکروفون (برای تمرین‌های 🎤 گفتاری) را مسدود می‌کنند. اجرا از طریق یک سرور محلی (حتی همین سرور ساده) این مشکل را حل می‌کند.

## دیپلوی روی Vercel

اپ کاملاً استاتیک است (بدون build، بدون API سمت سرور) — فقط ریپو را به Vercel وصل کن؛ نیازی به تنظیم build command یا framework نیست. فایل `start-server.js`/`start-server.bat` فقط برای اجرای محلی هستند و Vercel نادیده‌شان می‌گیرد.

## کلید API (اختیاری)

برای فعال‌شدن «مکالمه زنده با معلم» و تصحیح آنلاین تمرین‌های نوشتاری، هر کاربر باید کلید API آنتروپیک خودش را در ⚙️ تنظیمات وارد کند. این کلید فقط در `localStorage` همان مرورگر ذخیره می‌شود و به هیچ سروری (جز مستقیم به API آنتروپیک) فرستاده نمی‌شود.

## نصب روی موبایل (PWA)

اپ یک Progressive Web App است (`manifest.json` + `sw.js`) — روی موبایل (اندروید/آیفون) از منوی مرورگر گزینه «Add to Home Screen» را بزن تا مثل یک اپ واقعی، با آیکون خودش، روی صفحه اصلی نصب بشه. نیازی به App Store/Google Play نیست. آیکون‌ها (`icon-192.png`, `icon-512.png`, `icon-512-maskable.png`) در ریشه پروژه هستند.

توجه: چون بدون build کار می‌کنیم (فایل‌ها اسم ثابت دارند، نه هش‌شده)، service worker با استراتژی stale-while-revalidate کار می‌کند — یعنی بعد از هر آپدیت واقعی اپ، ممکنه کاربر یک‌بار رفرش اضافه لازم داشته باشه تا نسخه جدید رو ببینه.
